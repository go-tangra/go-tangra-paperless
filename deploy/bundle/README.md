# paperless join bundle

Generated by the gateway (Gateway operations › Modules › paperless › Add).

    docker compose up -d

The bundle runs paperless with its own TimescaleDB (TLS, certificate from
the bundle's local CA), RustFS for document bytes, Tika and Gotenberg; only
the mesh ports (9955 gRPC, 9956 HTTP) are published, on the IP you gave.
`private/` holds credentials (the single-use enrolment token, the bundle's
TLS keys); `.env` holds generated passwords and the envelope key
(`GEN_KEY_1`, which seals stored secrets: back it up with the volumes);
`config.yaml` holds the event-bus password you gave. Keep them on this host
only. The enrolment token is valid for the
lifetime chosen in the wizard; after the first start the module renews its
identity itself.

paperless joins the core's event bus (Valkey, TLS) as user `paperless`:
the core's Valkey must accept that user from this host, with access to the
`platform:events:*` keys. Document processing events are published there so
the gateway relays them to the browser; the bundle runs no Valkey of its own.
